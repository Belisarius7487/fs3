# Third-party material

## Material Symbols (Google)

The subsystem icons in the bar's target view (weapons `my_location`,
sensors `radar`, navigation `explore`, communication `cell_tower`) are the
outlined SVG paths from the npm package `@material-symbols/svg-400`
(version 0.48.1), copied into `src/72_target.js` (`SUB_ICON_D`).

Licensed under the Apache License, Version 2.0 — full text in
`material-symbols-LICENSE.txt`. The paths are unchanged; they are drawn
filled through a canvas `Path2D`.

The engine icon (a bell nozzle lying on its side) is drawn by hand and is
not part of Material Symbols.
