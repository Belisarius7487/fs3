# FS3 Code Map

Where things live in `hlp_shooter_v<N>_logic.html`. The guide below is
hand-written; the index under "Full index" is regenerated by `codemap.py`.
Line numbers in the guide are left out on purpose — look the names up in the
index, which is refreshed with every version.

## How the file is put together

- One HTML file: `<style>` at the top, a few `<img>` tags, then one `<script>`.
- Image data is **not** in this file. The packer (`build_game.py`) fills
  `SPR_DATA`, `ICON_DATA`, `PLANET_DATA`, `SUN_DATA` and `MOUNTS` from the
  folders, and replaces `@@FS3_ASSET:<path>@@` tokens with files from
  `images/` and `nebulae/`. Leave those blocks empty in the logic file.
- `GAME_VERSION` is set by the packer from the file name.
- Section banners (`// ── NAME ──`) at column 0 divide the file; the index
  follows them. Some section names are German, some English.

## Where to look for …

| Topic | Start here |
|---|---|
| Main loop | `stepUpdate()` (fixed time step, `TICK_HZ`) → `update()` and `draw()` |
| Game states | `GS`: `'title'`, `'shipselect'`, `'playing'`, `'gameover'`; switched in `draw()`, `playerDie()`, `onShipScreenClick()` |
| Wave flow | `nextWave()` → `getWaveDef(n)` → `buildScripted()` / `buildFS1Wave()` / `buildTestWave()` / `rollWave()` → `buildWave(spec)` |
| Written missions (Hammer of Light) | data `SCRIPT_WAVES`; runtime in GESCHRIEBENE WELLEN: `EV`, `byId()`, `evTrig()` (triggers), `evFire()` (effects), `tickEvents()`, `scriptUnit()` |
| Random waves | ACHSE 1 `COMPOS`, ACHSE 2 `OBJ`, `OBJ_OK`/`objFits()`, `WAVE_SEQ`, BOSSFENSTER `rollWave()` |
| Wing gating | `gateWings`, `gateWing`, `liveThreatCount()` |
| Docking and cargo | DEFECTORS: `dockPoint()`, `dockOffset()`, `claimCargo()`, `cargoStillWanted()`, `carryCargo()`, `dropCargo()`, `leaveEmpty()`, `cargoLost()`, `tickCarry()`, `tickDocking()`; constants `DOCK_SPD`, `DOCK_NEAR` in SUBSYSTEMS |
| Defectors, escorts, escapers | DEFECTORS: `spawnDefector()`, `defect()`, `evPending()`, `escPending()`, `crossPending()`, `tickEscapers()`, `tickDefectors()` |
| Non-combatants (player-only targets) | `playerOnly()` in ESCORTS; freighter branch inside `mkEnemy()` |
| Creating enemies, size, toughness | GROESSE UND ZAEHIGKEIT: `HULL_LEN`, `hullScale()`, `hullPoints()`, `mkEnemy()` |
| Damage and death | `damageEnemy()`, `killEnemy()`, `playerDie()` |
| Factions | `factionOf()`, `typeFac()`, `FAC_TAG`, `currentFaction` |
| Allies and support tickets | ESCORTS: `ALLY_DEFS`, `mkAlly()`, `callAlly()`, `updateAllies()`; SUPPORT TICKETS: `tickets`, `spawnTicket()` |
| Weapons and mounts | ENEMY ARMAMENT: `mountsFor()`, `mountList()`, `entMounts()`, `initWeapons()`, `capitalFire()`; ENGINE PLUMES: `initBeams()`, `updateBeams()` |
| Small ship AI | SMALL SHIP FLIGHT: `flySmall()`, `smallTarget()`, `smallFire()` |
| Targeting | TARGETING: `canLockOn()`, `pickBeamTarget()` |
| Subsystems | SUBSYSTEMS: `SUB_DEFS`, `initSubsystems()`, `subHit()` |
| Ship selection (to be removed) | `selectedShip`, `PSHIPS`, `drawShipSelect()`, `onShipScreenClick()`; `handleShipSelect_unused()` is dead code |
| HUD and top bar | `drawHUD()` (sub-banners SCORE, WAVE, HULL, SHIELD, LIVES, SEC WEAPON BUTTON, SUPPORT, PAUSE, SETTINGS inside it), `drawGear()` |
| Call menu | CALL MENU: `drawCallMenu()`, `toggleCallMenu()` |
| Settings and ECO mode | `ECO`, `ecoSave()`, `applyResolution()`; SETTINGS PANEL: `settingsRows()`, `drawSettings()` |
| Wave modifiers (nebula, debris, EMP, ambush) | WRECKAGE: `MOD_LIST`, `rollWaveMod()`; ASTEROIDEN for debris and EMP drawing |
| Input | TOUCH & MAUS STEUERUNG |
